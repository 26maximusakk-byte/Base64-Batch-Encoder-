# 🔐 Base64 Batch Encoder — кодируй сотни файлов за секунду

> «Один файл — хорошо, а тысяча — лучше»

**Base64 Batch Encoder** — это набор консольных утилит для массового кодирования файлов в формат Base64.  
Программа обрабатывает все файлы в указанной папке (включая вложенные), сохраняя результаты в виде отдельных `.b64` файлов или в единый JSON-отчёт.

## 🚀 Особенности
- 📁 Массовое кодирование всех файлов в папке (включая подпапки).
- ⚡ Параллельная обработка (многопоточность) для максимальной скорости.
- 📊 Прогресс-бар и статистика обработки.
- 📤 Экспорт результатов в форматах: отдельные `.b64` файлы, единый JSON-отчёт, CSV-отчёт.
- 🔄 Поддержка декодирования (восстановление файлов из Base64).
- 🎛️ Настройка через аргументы командной строки или JSON-конфиг.
- 🎨 Цветной вывод в терминале.
- 💾 Автосохранение лога обработки.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python batch_base64.py ./folder`       |
| Go         | стандартная библиотека               | `go run batch_base64.go ./folder`       |
| JavaScript | Node.js, `fs`, `path`                | `node batch_base64.js ./folder`         |
| Java       | стандартная библиотека               | `javac batch_base64.java && java batch_base64 ./folder` |
| C#         | .NET (или mono)                      | `dotnet run ./folder`                   |
| Rust       | `rayon`, `serde_json`                | `cargo run -- ./folder`                 |
| Ruby       | `find` (встроенный)                  | `ruby batch_base64.rb ./folder`         |
| PHP        | стандартная библиотека               | `php batch_base64.php ./folder`         |
